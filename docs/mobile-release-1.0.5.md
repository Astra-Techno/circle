# Android beta 1.0.5 (build 6): reliable Memories and everyday navigation

Group timelines, Saved Memories and server search now use independent paginated queries rather than filtering only the loaded Home page. Appearance preferences persist on the device; text drafts are scoped to the signed-in server/account and offer Resume or Discard. Native invitation entry accepts supported invite URLs, and live navigation shows the available Home, Groups and You destinations. Preview mode retains its full navigation.
