# Contact-first group invitations

27 October 2026. This batch replaces the long-link-first server invite screen with a single-contact flow. Tap Invite to open the Android selected-phone-record picker, confirm an international number, then confirm sending. A registered eligible recipient receives a persistent CIRCLE invitation; an unknown/inactive number offers WhatsApp/SMS link sharing. Nobody joins without accepting. Copy invite link remains independent of contact selection; expiry/reset/usage controls are under Manage invite link. Preview remains isolated.

Only the selected E164 number is sent after confirmation; no address-book enumeration/upload, contact cache, automatic SMS, or READ_CONTACTS/WRITE_CONTACTS/SEND_SMS permission is introduced. Local numbers require explicit country-code correction. WhatsApp opens its own recipient chooser; SMS prepares the chosen number. External apps require user confirmation and do not prove delivery.

API contract 0.3.7 adds POST /groups/{id}/contact-invitations, recipient-owned list/detail and accept/decline. Sender must be an active exact-group admin or have member invite permission. Attempts are limited to 20/hour per sender, including misses and forbidden attempts after validation. No recipient profile/number is returned by lookup. Pending invites last seven days; live duplicates reuse an id, terminal invites have a 24-hour cooldown, renewed invites use immutable new ids. Bans, parent membership, inviter permission and removal are rechecked at acceptance. Member-issued invitations obey manual approval; admin-issued invitations still need recipient consent. Repeated acceptance never restores subsequently removed membership. Parent exit invalidates pending descendant invitations.

Groups and You expose a recipient inbox even with push denied/disabled. Lists use bounded limit/offset pagination, with account/API/session guards and recipient validation. Invitations can be accepted or declined; loading/error/retry and history states are explicit. No background inbox polling is added.

Migration 011 persists invitations; 012 adds group.invitation outbox references. Capture is transactional and deduplicated, honors global/groups preferences and registered Android sessions. Delivery rechecks current invitation/actor/recipient/parent/ban/session/quiet-hours state. The exact eight-string-key reference envelope is separate from the unchanged Memory envelope and contains no contact details or private text. Foreground/background/taps reauthorize recipient-owned invitation details; generated navigation opens the inbox. OS delivery is not guaranteed by successful creation. Explicit CIRCLE_PUSH_ENABLED remains optional in source; this release enables it.

Shared/copied links retain https://<configured-origin>/invite.html#<token>, restrictive browser fallback and existing join authorization. Session/API/permission checks run before and after external selection and before copying/composition. No real invitations or pushes were sent during automated tests.

Validation: backend dedicated circle_test 184 tests / 3,087 assertions, PHPStan clean; OpenAPI parses and internal references resolve. Phone/tablet light/dark at 200% text rendered and inspected; Copy works without contact selection. Final Flutter/release results are in PROJECT_STATE.md and the build12 release record. Native contacts, WhatsApp/SMS, update installation and actual foreground/background/closed push still require owner device acceptance; no device is attached here.
