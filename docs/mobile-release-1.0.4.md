# Android beta 1.0.4 (build 5): You screen improvements

Implements the review of the signed-in You screen: removes the long introduction and server address from everyday headers, uses the account's initial in the shell avatar, and adds a raised lavender profile card with working Edit profile and Your groups actions. Connection details are under Account → Connection. Saved Memories now has a bookmark illustration, concise explanation and a Browse Memories action when empty; saved-item navigation is retained. The existing fictional-preview label remains explicit.

Edit profile updates the display name through the reviewed PATCH /me endpoint via the API client and session notifier. Names are validated before sending. Successful saves update the visible account and stored account metadata; failed saves keep the old name and allow retry. No HTTP is performed in widgets, no backend contract changes are introduced, and no existing live account was changed during validation.
